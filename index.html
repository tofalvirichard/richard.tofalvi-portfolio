Looker Studio + Google Cloud projektek

BigQuery, Cloud Run, automatizált adatfrissítés, modern dashboardok

Data Pipeline & Architecture

Google Cloud

A Looker Studio projektjeim egy Google Cloud alapú adatpipeline-re épülnek. Az adatgyűjtés különböző API-kból történik Python alapú feldolgozással, amely Cloud Run környezetben fut. A feldolgozott adatok BigQuery adattárházba kerülnek, ahol strukturált, riportolható adatkészletek jönnek létre. Ezekre a táblákra épülnek a Looker Studio dashboardok, amelyek interaktív elemzést és vizualizációt biztosítanak. A pipeline egyes projektekben természetes nyelvi feldolgozást (NLP) és gépi tanulási modelleket (Machine Learning) is használ.

API data ingestion Python data processing Cloud Run execution BigQuery data warehouse Looker Studio dashboards Automated data pipelines NLP Machine Learning Sentiment Analysis

Looker Studio dashboard, amely az amerikai Big Tech vállalatok (Apple, Microsoft, Nvidia, Amazon, Google, Meta stb.) részvénypiaci teljesítményét elemzi. Az adatokat API-n keresztül gyűjtő Python script tölti a Google Cloud környezetben futó pipeline segítségével BigQuery táblákba. A Looker Studio erre a strukturált adattárra építve biztosít interaktív pénzügyi riportot.
